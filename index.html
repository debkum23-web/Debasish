Working Rules

How I build with AI

Four rules I've picked up from shipping this stuff, each learned on a real project rather than from a blog post.

The LLM never touches the data directly

In the Message Center platform, the LLM interprets the question but a separate search API runs the query. That wall was in the first design, and it's why security and compliance conversations went smoothly.

Ask, don't guess

When a search query is ambiguous, the agent asks a clarifying follow-up instead of returning its best guess. A wrong answer costs more trust than a follow-up question costs time.

AI finds the signal, people make the call

Copilot classified 1,200 tickets in hours — but which two features to build, and in what order, was human judgment applied to what it surfaced. I keep that boundary deliberate.

Ship into an existing workflow

Every AI product I've shipped replaced something people already did — a daily email, a manual review. Nobody had to adopt a new habit, which is most of why adoption happened at all.
