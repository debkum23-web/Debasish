Message Center Intelligence Platform

Thought Process

How I think as a product owner

The same rules show up in the office work and the capstone — that's how you can tell they're real.

Start from the decision, not the request

Leadership asked for a better email; the real spec was history, urgency, and ownership. The capstone schema began the same way — from the questions Legal and Sourcing ask, not from everything a contract contains.

The LLM never touches the data directly

In the Message Center platform, the LLM interprets the question but a separate search API runs the query. That wall was in the first design, and it's why security and compliance conversations went smoothly.

Ask, don't guess

An ambiguous search query gets a clarifying follow-up, not a best guess. In the capstone, ambiguous contract language gets a null with a rationale, not an invented value. Same rule, two products.

AI finds the signal, people make the call

Copilot classified 1,200 tickets in hours — but which features to build was human judgment. The capstone routes 23% of its results to human review by design. I keep that boundary deliberate.

Ship into an existing workflow

Every AI product I've shipped replaced something people already did — a daily email, a manual review. Nobody had to adopt a new habit, which is most of why adoption happened at all.
